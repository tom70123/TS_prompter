# 新聞提詞機

依節目聲音自動滑動字幕的提詞網頁。主播稿用語音辨識對位，SOT（主播念完後播出的整段影片）可事先錄音、自動辨識並記住每句字幕的時間，播出時依記憶推進。

## 使用方式

用 Chrome 或 Edge 開啟網址即可，不需安裝。

1. 載入稿件（RTF 或 TXT），或按「載入範例」試用。
2. 拖曳調整播出順序，可插入廣告時段。
3. （選擇性）按「SOT 字幕時間」，錄下每則 SOT 的聲音，自動算出字幕時間。
4. 按「開始」。

播出中的操作：滾輪或 ↑↓ 上下一句、左鍵下一句、右鍵上一句、空白鍵暫停或開始時間軸、M 左右鏡像、U 上下顛倒、Esc 回設定。

## 資料與隱私

- 稿件、錄音、字幕時間都只存在使用者自己的瀏覽器裡，不會上傳到這個網站。
- 主播稿的即時語音辨識使用瀏覽器內建服務，聲音會送到瀏覽器供應商（Chrome 為 Google）處理。
- SOT 自動辨識在使用者自己的電腦上執行；第一次使用時會從網路下載辨識模型與程式庫（Hugging Face、jsDelivr）。
- 字幕時間可用「匯出時間檔」備份或帶到其他電腦。清除瀏覽器資料會一併刪除錄音與時間。
